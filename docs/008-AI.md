# PhysioTrust AI Module Specifications

---

## 1. AI Modules Overview

PhysioTrust integrates 6 specialized AI modules:

```
[ Signal Quality AI ] ──► [ Context AI ] ──► [ Reliability AI ]
                                                  │
                                                  ▼
[ Prediction AI ] ◄── [ Explanation AI ] ◄── [ Personalization AI ]
```

---

## 2. Module Specifications

### Module 1: Signal Quality AI
- **Goal**: Evaluate signal integrity and detect motion artifacts, baseline drift, and flatline dropouts.
- **Inputs**: 5.0-second 1D signal window vector ($x \in \mathbb{R}^{1800}$).
- **Extracted Features**: Variance $\text{Var}(x)$, Shannon Entropy $H(x)$, Kurtosis $K(x)$, SNR proxy (dB), Zero Crossing Rate (ZCR).
- **Mapping Strategy**: Deterministic non-linear sigmoidal functions mapping statistical moments to normalized sub-scores $[0.0, 1.0]$.
- **Target Metrics**: Signal Quality Index (SQI) classification F1-Score $> 0.94$.

### Module 2: Context AI
- **Goal**: Recognize physical activity states (Rest, Sleep, Walking, Running) from accelerometry / heart rate dynamics.
- **Inputs**: 3-axis accelerometer signals ($a_x, a_y, a_z$) or user activity state tag.
- **Output**: Context state class label and dynamic reliability threshold selection ($\theta_{\text{rest}}=0.60, \theta_{\text{sleep}}=0.70, \theta_{\text{walk}}=0.40, \theta_{\text{run}}=0.30$).
- **Evaluation Metric**: Context Classification Accuracy $> 92.0\%$.

### Module 3: Reliability AI (Trust Engine)
- **Goal**: Formulate unified Reliability Score ($0.0 – 1.0$).
- **Model Strategy**: Weighted non-linear sigmoid ensemble:
  $$R(x) = \text{Clip}\left( w_e \cdot S_{\text{entropy}}(x) + w_k \cdot S_{\text{kurtosis}}(x) + w_v \cdot S_{\text{variance}}(x), 0.0, 1.0 \right)$$
- **Evaluation Metric**: Area Under ROC Curve (AUROC) $> 0.96$ for clean vs noisy ECG window discrimination.

### Module 4: Personalization AI
- **Goal**: Learn subject-specific physiological baselines over multi-day time horizons.
- **Model Strategy**: Running Bayesian mean/variance update model conditioned on Context Gatekeeper acceptance:
  $$\mu_{t+1} = \mu_t + \alpha (v_{t+1} - \mu_t) \quad \text{if } \text{Decision}_{t+1} = \text{ACCEPTED}$$
- **Outputs**: Subject baseline mean $\mu_{\text{baseline}}$ and standard deviation $\sigma_{\text{baseline}}$.

### Module 5: Explanation AI (`TrustExplainer`)
- **Goal**: Convert feature vectors and gatekeeper decisions into human-readable text attributions.
- **Inputs**: `ReliabilityResult`, `ContextEvaluationResult`, subject baseline statistics.
- **Output**: Structured `ExplanationSummary` containing headline, factor attributions, confidence percentage, and natural language summary text.

### Module 6: Prediction AI (`TrendTracker`)
- **Goal**: Predict physiological trend direction and detect early fatigue or stress deterioration.
- **Inputs**: Time-series buffer of window trust scores $R_1, R_2, \dots, R_N$.
- **Outputs**: Drift slope $m$, mean trust score, and trend state label (`improving`, `stable`, `degrading`).
