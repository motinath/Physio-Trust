# PhysioTrust AI Subsystem Architecture

```
physiotrust/ai/
├── signal_quality/     -> SQI calculation (SNR, drift, noise, kurtosis)
├── trust/              -> Trust score classification
├── context/            -> Activity context evaluation
├── personalization/    -> Adaptive baseline & circadian rhythm
├── explainability/     -> SHAP feature attribution & NLG
└── prediction/         -> Multi-horizon time-series forecasting
```
