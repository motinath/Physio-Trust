# PhysioTrust UI Component Library

1. **`OscilloscopeCanvas`**: HTML5 Canvas dual-trace renderer (360 Hz live stream).
2. **`TrustScoreGauge`**: SVG circular progress gauge with dynamic status stroke.
3. **`FeatureAttributionMeters`**: Multi-bar SHAP attribution visualizer.
4. **`ForecastTable`**: Multi-horizon predictions table.
5. **`ScenarioSimulatorCards`**: Interactive "What If" simulation cards.
6. **`ResearchExperimentsTable`**: Audit log laboratory table.
