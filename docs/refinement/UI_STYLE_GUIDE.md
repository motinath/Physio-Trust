# PhysioTrust UI Style Guide

## Typography
- **Primary Font**: `Inter`, `system-ui`, `-apple-system`, `sans-serif`.
- **Monospace Font**: `JetBrains Mono`, `Fira Code`, `monospace` (used for telemetry numbers, ECG coordinates, and technical XAI output).

## Spacing & Layout
- **Grid Layout**: Responsive CSS Grid (`repeat(auto-fit, minmax(...))`).
- **Gap Standard**: `1.25rem` grid spacing, `0.75rem` panel padding.
