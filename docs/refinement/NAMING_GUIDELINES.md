# PhysioTrust Codebase Naming Conventions

| Asset Type | Standard Convention | Example |
| :--- | :--- | :--- |
| **Python Files** | `snake_case` | `prediction_engine.py` |
| **Python Classes** | `PascalCase` | `PredictionEngine` |
| **Python Functions** | `snake_case` | `forecast_all()` |
| **Python Variables** | `snake_case` | `trust_score` |
| **React Components** | `PascalCase` | `OscilloscopeCanvas.jsx` |
| **Database Tables** | `snake_case` | `prediction_history` |
| **API Endpoints** | `RESTful /api/v1/` | `/api/v1/prediction` |
| **Environment Variables** | `UPPER_CASE` | `SECRET_KEY` |
